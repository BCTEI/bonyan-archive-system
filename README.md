# نظام الأرشيف الإلكتروني - مركز البنيان

تطبيق سطح مكتب لإدارة الأرشيف الإلكتروني لمركز البنيان، يعمل بدون اتصال بالإنترنت ويستخدم قاعدة بيانات SQLite محلية.

## المتطلبات

- Node.js 20 أو أحدث
- Bun (مدير الحزم)
- Windows 10/11 (64-bit)

## التثبيت

```bash
bun install
```

إذا واجهت مشكلة في تحميل وحدة `better-sqlite3`، شغّل:

```bash
bun run postinstall
```

## التشغيل في وضع التطوير

```bash
bun run start
```

## بناء النسخة الإنتاجية

```bash
bun run build:prod
```

## بناء المثبت (Windows)

```bash
bun run dist
```

> ملاحظة: على Linux يتطلب بناء مثبت NSIS تثبيت **Wine**. إذا لم يكن Wine متوفراً، يمكنك إنشاء نسخة محمولة (.exe واحد) بدون تثبيت:

```bash
bun run build:win
```

## بناء حزمة Debian / Linux

```bash
# حزمة .deb
bun run build:linux-deb

# AppImage
bun run build:linux
```

ثم ثبّت الحزمة على Debian/Ubuntu:

```bash
sudo dpkg -i release/bonyan-archive-system-*.deb
```

## تسجيل الدخول الافتراضي

- **اسم المستخدم:** `admin`
- **كلمة المرور:** `admin123`

## إدارة المستخدمين

يتوفر نظام كامل لإدارة المستخدمين من قائمة **إدارة المستخدمين** (متاحة للمدير فقط):

- **مدير النظام (admin):** كل الصلاحيات (إدارة المستخدمين + الوثائق + التدقيق).
- **محرر (editor):** إضافة/تعديل/حذف الوثائق + عرض التدقيق.
- **مشاهد (viewer):** عرض الوثائق فقط بدون تعديل.

يمكن للمدير إضافة مستخدمين جدد، تعديل صلاحياتهم، تفعيل/تعطيل الحسابات، ومتابعة سجل دخول/خروج المستخدمين.

### الصلاحيات على مستوى الواجهة والـ IPC

- أزرار إضافة/تعديل/حذف الوثائق تظهر فقط للمدير والمحرر.
- استيراد البيانات ومسح السجل متاحان للمدير فقط.
- جميع عمليات التعديل في العملية الرئيسية (main process) تتحقق من صلاحية المستخدم الحالي.
- الحسابات المعطّلة لا يمكنها تسجيل الدخول.
- يوجد نظام ACL لصلاحيات المجلدات: المدير يملك كل شيء، المحرر يبدأ بصلاحية عرض فقط، المشاهد لا يملك شيئاً إلا ما يُمنح له.

## لوحة التحكم

- إحصائيات الوثائق (إجمالي، صادر، وارد، مراسلات).
- رسم بياني توضيحي لأنواع الوثائق.
- سجل دخول/خروج المستخدمين لليوم الحالي.
- آخر الوثائق المضافة.
- إجراءات سريعة تظهر/تختفي حسب صلاحية المستخدم.

## التنقل السريع

- زر 🏠 الرئيسية في الشريط العلوي للعودة للوحة التحكم من أي صفحة.
- شريط مسار التنقل (Breadcrumb) أعلى المحتوى.
- ضغط مفتاح `Escape` يعيدك للوحة التحكم.

## موقع قاعدة البيانات

- **Windows:** `%APPDATA%\bonyan-archive-system\archive.db`
- **Linux:** `~/.config/bonyan-archive-system/archive.db`

## النسخ الاحتياطي والاستعادة

- استخدم زر **تصدير** في شاشة الوثائق لحفظ نسخة احتياطية بصيغة JSON.
- استخدم زر **استيراد** لاستعادة البيانات من ملف JSON (دمج أو استبدال).
